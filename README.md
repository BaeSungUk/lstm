# 쇼핑 탐색 경로 예측: 작은 LSTM 실험

쇼핑 클릭 이력으로 다음 카테고리를 예측하는 PyTorch 미니 프로젝트입니다. 실제 테스트 22,570건에서 LSTM의 정확도는 **82.16%**였지만, 직전 카테고리 반복 기준선과 같았으며 **전환 구간 정확도는 0%**였습니다. 이 실험에서는 LSTM의 추가 이점이 확인되지 않았습니다.

## 1. 문제 정의

방문 세션에서 지금까지 관찰된 카테고리를 이용해 바로 다음 클릭의 카테고리 하나를 예측합니다. 구매 여부, 이탈, 클릭 사이의 소요 시간은 예측하지 않습니다. 핵심 질문은 “더 긴 이력이 직전 카테고리를 반복하는 규칙보다 도움이 되는가?”입니다.

## 2. 데이터

[UCI Clickstream Data for Online Shopping](https://archive.ics.uci.edu/dataset/553/clickstream+data+for+online+shopping)의 2008년 4~8월 임부복 상점 클릭 기록을 사용했습니다. 원본은 165,474행, 24,026개 세션입니다. `session ID`는 방문 묶음이며 고객 ID가 아닙니다. `order`는 세션 내 클릭 순서입니다.

예측 대상은 `page 1 (main category)`입니다: 1 바지, 2 치마, 3 블라우스, 4 세일. 세일은 사이트 메뉴지만 원본 범주를 유지합니다. 코드와 예측 CSV 내부에서는 0~3으로 변환합니다.

데이터 인용: *Clickstream Data for Online Shopping* [Dataset]. (2019). UCI Machine Learning Repository. [DOI: 10.24432/C5QK7X](https://doi.org/10.24432/C5QK7X). 라이선스는 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)입니다. 원 연구: Mariusz Łapczyński와 S. Białowąs (2013), *Discovering Patterns of Users' Behaviour in an E-shop - Comparison of Consumer Buying Behaviours in Poland and Other European Countries*, Studia Ekonomiczne. 이 프로젝트는 원본을 세션별 다음 클릭 예제로 가공합니다.

## 3. 전처리와 분할

완전히 동일한 행을 제거하고, 필수 필드 결측·잘못된 레이블·충돌하는 클릭 순서는 해당 세션 전체를 제외합니다. 날짜가 클릭 순서와 반대로 이동하는 세션도 제외합니다. 이번 원본에서 결측, 중복, 비정상 세션, 분할 경계를 넘는 세션은 모두 0건이었습니다.

세션 시작 날짜를 기준으로 약 70/15/15%로 분할합니다. 같은 날짜와 같은 세션을 여러 분할에 넣지 않으며 경계를 넘는 세션은 제외합니다. 각 세션의 첫 클릭 이후 모든 클릭이 목표가 되고, 앞선 클릭만 입력으로 사용합니다.

| 분할 | 날짜 | 세션 수 | 클릭 수 | 다음 클릭 예제 수 |
| --- | --- | ---: | ---: | ---: |
| 학습 | 2008-04-01~06-29 | 16,835 | 114,928 | 98,093 |
| 검증 | 2008-06-30~07-21 | 3,620 | 24,405 | 20,785 |
| 테스트 | 2008-07-22~08-13 | 3,571 | 26,141 | 22,570 |

테스트는 이후 시기의 새 방문에 대한 평가입니다. 세션 목록은 `results/split_manifest.csv`, 정제 기록과 원본 SHA-256은 `results/data_audit.json`에 있습니다.

## 4. 입력 구조

카테고리를 4차원 원-핫 벡터로 표현합니다. 범주 번호의 대소관계가 없으므로 연속형 숫자로 넣지 않으며, 원-핫 입력에는 정규화가 필요하지 않습니다. 가격·국가·상품 코드는 기본 실험에서 제외했습니다.

최대 이력은 1/5/10개입니다. 길이 10의 기본 입력 모양은 `(batch, 10, 4)`이며 배치 크기는 64입니다. 짧은 이력은 오른쪽에 0을 채우고 실제 길이를 전달합니다. 예를 들어 `[바지, 바지, 치마]`에서는 `[바지] → 바지`, `[바지, 바지] → 치마`라는 예제를 만듭니다. 모든 이력 길이는 동일한 목표 클릭을 평가합니다.

## 5. 모델

단방향 단층 `LSTM(input_size=4, hidden_size=32, num_layers=1)`에 `Linear(32, 4)`를 연결합니다. 학습 파라미터는 **4,996개**입니다. `pack_padded_sequence`로 마지막 실제 클릭의 은닉 상태를 사용하므로 패딩이 최종 상태를 바꾸지 않습니다. 출력은 4개 클래스의 logits이며 학습 전에 softmax를 적용하지 않습니다.

## 6. 학습 방법

CrossEntropyLoss, Adam(학습률 0.001), 배치 크기 64, 최대 20 epoch, 검증 loss 기준 patience 4를 사용했습니다. 최소 검증 loss의 체크포인트를 복원한 뒤 테스트합니다. 각 길이마다 시드 42로 독립 학습하며 CPU 스레드는 2개입니다.

| 모델 | 선택 epoch | 실제 epoch | 최저 검증 loss | 학습 시간(초) |
| --- | ---: | ---: | ---: | ---: |
| LSTM-1 | 4 | 8 | 0.683378 | 22.18 |
| LSTM-5 | 13 | 17 | 0.673926 | 78.13 |
| LSTM-10 | 16 | 20 | 0.670157 | 126.66 |

실측 환경은 Python 3.11.15, PyTorch 2.5.1+cpu입니다. 전체 환경과 설정은 `results/config.json`, epoch별 손실은 `results/history.json`에 있습니다. 시간은 실행 환경에 따라 달라집니다.


## 7. 평가 결과

기준선은 직전 카테고리 반복과 학습 데이터의 1차 Markov 전이별 최빈 카테고리입니다. 테스트의 동일한 22,570개 목표에 Accuracy, Macro F1, 혼동행렬을 계산합니다. 정답이 직전 범주와 같은 유지 구간은 18,544건, 다른 전환 구간은 4,026건입니다. 전환 여부는 정답을 사용한 사후 분석이며 예측 시점에는 알 수 없습니다.

| 모델 | 전체 정확도 | Macro F1 | 유지 정확도 | 전환 정확도 |
| --- | ---: | ---: | ---: | ---: |
| Repeat-last | 82.16% | 0.8171 | 100.00% | 0.00% |
| Markov | 82.16% | 0.8171 | 100.00% | 0.00% |
| LSTM-1 | 82.16% | 0.8171 | 100.00% | 0.00% |
| LSTM-5 | 82.16% | 0.8171 | 100.00% | 0.00% |
| LSTM-10 | 82.16% | 0.8171 | 100.00% | 0.00% |



혼동행렬의 행은 정답, 열은 예측입니다. 테스트 정답의 범주별 지원 수는 바지 6,274 / 치마 4,297 / 블라우스 5,295 / 세일 6,704건입니다. 원시 값은 `results/metrics.json`, 표는 `results/metrics.csv`, 개별 예측은 `results/predictions.csv`에서 확인할 수 있습니다.


## 8. 해석과 한계

**관측:** 모든 모델이 테스트에서 직전 범주를 그대로 예측했습니다. Markov의 학습 전이 행렬에서도 각 행의 최빈 다음 범주는 자기 자신입니다. 전체 정확도 82.16%는 테스트의 범주 유지 비율과 같습니다. LSTM의 검증 loss는 길이 1보다 10에서 낮지만 테스트 최빈 클래스 예측은 동일합니다. 이 결과만으로 긴 의존성을 학습했거나 더 긴 이력이 우월하다고 주장할 수 없습니다.

**가능한 설명:** 범주 유지가 많아 최빈 범주를 선택하는 것이 유리하고, 범주만 사용하는 입력으로는 전환 신호를 포착하기 어려울 수 있습니다. 이는 가설이며 특징 추가나 별도 실험으로 검증해야 합니다. 추후 상품·가격 정보를 추가하거나 전환 확률의 보정, 여러 시드의 변동성을 평가할 수 있습니다.

단일 시드와 단일 상점의 오래된 기록이므로 현대 쇼핑몰 전체로 일반화할 수 없습니다. 고객 ID가 없어 분할 사이 동일 고객의 재방문 여부도 확인할 수 없습니다. 테스트 결과를 보고 최적 이력 길이를 선정하지 않았습니다.

## 실행

프로젝트 루트에서 Python 3.11 가상환경을 준비합니다. Windows PowerShell 예시:

```powershell
py -3.11 -m venv .venv
.venv/Scripts/python.exe -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m src.train
```

첫 실행에 UCI 원본을 `data/`로 다운로드합니다. 연결 실패 시 오류의 원인을 확인하고 다시 실행하거나 원본 CSV를 `data/e-shop clothing 2008.csv`에 둡니다. 기본 학습 명령은 `results/`를 갱신하므로 기존 결과를 보존하려면 `--output results-new`를 지정합니다. 빠른 실행 점검에는 `--epochs 1 --output results-smoke`를 사용할 수 있으며 제출 결과와는 다릅니다.

학습 후 그림만 다시 생성하려면 `.venv/Scripts/python.exe -m src.report`를 실행합니다.

- `README.md`: 프로젝트 설명, 기존 실험 결과 요약, 실행 방법
